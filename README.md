## Clone Repository
Run `git clone https://github.com/Biduff/FP_IMK.git`

## Laravel
Run `composer install` on trashblazer directory

Run `composer require guzzlehttp/guzzle` on trashblazer directory

Run `cp .env.example .env` on trashblazer directory

Run `php artisan migrate:fresh --seed` on trashblazer directory

Run `php artisan storage:link` on trashblazer directory

Run `php artisan key:generate` on trashblazer directory

Then run `php artisan serve` to start the website

## Flask Setup
Run `pip install flask torchvision torch pillow` on flask_api directory 

Run `pip install flask-cors` on flask_api directory

Run `python app.py` on flask_api directory to start the model
